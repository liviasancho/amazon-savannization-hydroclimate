# Data availability notes

## Landsat / USGS catalogue availability

The Landsat products used in the land-surface-temperature analysis were
downloaded from USGS EarthExplorer at the time the original analysis was
performed.

During repository preparation, the authors found that the exact products
originally used for some analysed dates could no longer be retrieved under the
same catalogue configuration.

The 2020 scene was verified as:

`LC08_L2SP_223068_20201002_20201015_02_T1`

Acquisition date:

`2020-10-02`

The original locally archived files used for the 2013 and 2026 analyses have
been retained by the authors, but the corresponding catalogue availability is
currently being clarified with USGS.

This repository documents the metadata available from the original analysis
and does not substitute unavailable scenes with different products.

Future repository releases may update this provenance information if further
clarification is provided by USGS.

## LST spatial interpretation

The LST analysis uses representative critical scenes within the southern and
southeastern Amazonian deforestation frontier.

The scenes do not necessarily share an identical Landsat path/row or spatial
footprint and should therefore not be interpreted as a pixel-by-pixel temporal
analysis of one fixed location.

The approximate analysis extent is delimited by the following geographic
coordinates:

1. 13°11'21"S, 52°36'39"W
2. 08°42'11"S, 52°34'01"W
3. 08°47'24"S, 47°35'32"W
4. 13°16'29"S, 47°26'58"W
