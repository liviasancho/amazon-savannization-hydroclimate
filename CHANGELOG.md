# Changelog

All notable changes to this repository will be documented here.

## [1.0.0] - 2026-10-20

### Added

- SPEI calculation workflow using BR-DWGD precipitation and reference evapotranspiration.
- SPEI-1, SPEI-3, SPEI-6, and SPEI-12 calculations.
- Climate-extreme workflow for WSDI, SU35, TXx, CDD, R1mm, and PRCPTOT.
- Pettitt change-point analysis.
- Kernel-density comparison of climate extremes.
- Derived Arc of Deforestation spatial dataset and methodology.
- MapBiomas Collection 11 land-cover workflow documentation.
- Atmospheric-blocking provenance through the RiskClima repository.
- Mann-Kendall analyses of SPEI and atmospheric blocking.
- Blocking-SPEI lagged and spatial relationship analyses.
- Landsat land-surface-temperature workflow documentation.
- Dataset provenance and reproduction documentation.
- Author and contribution metadata.
